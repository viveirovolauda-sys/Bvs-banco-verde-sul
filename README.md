# BVS - Banco Verde Sul 🌱

Plataforma de conexão para a intermediação de Reserva Legal, conectando quem possui excedentes de áreas legais com aqueles que possuem déficit. O projeto busca promover a sustentabilidade e a conformidade ambiental, facilitando negociações seguras e eficientes entre proprietários rurais.

## Objetivo
Simplificar e promover a compensação ambiental ao conectar partes interessadas em cumprir suas obrigações legais de Reserva Legal por meio de uma plataforma inovadora.

## Funcionalidades:
- Cadastro de proprietários com suas áreas (especificando matrícula, área total, CAR, RL existente).
- Validação do **Cadastro Ambiental Rural (CAR)** para garantir que está analisado.
- Pareamento inteligente entre propriedades com excedente e déficit de RL.
- Contratos de intermediação automatizados, incluindo:
  - Identificação das duas partes.
  - Percentual de intermediação de 10%.
  - Forma de pagamento e cláusulas contratuais.
  - Prazo de validade do contrato.
- Processamento de pagamentos diretamente na plataforma (ex.: PIX).

## Tecnologias (planejado):
- **Back-end**: Node.js, para APIs rápidas e escaláveis.
- **Front-end**: React Native, para desenvolvimento de apps em Android e iOS.
- **Banco de Dados**: PostgreSQL, para armazenar dados estruturados como matrículas e validações.
- **APIs externas**: Integração com sistemas oficiais como CAR e geolocalização.

## Estrutura do Repositório
- `frontend/`: Aplicação cliente (telas de cadastro, busca, etc.).
- `backend/`: APIs e lógica do servidor.
- `docs/`: Documentação e modelos de contrato.
- `prototypes/`: Mockups e wireframes para o design do projeto.
